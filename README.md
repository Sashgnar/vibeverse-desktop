# VibeVerse desktop

Downloads of the [VibeVerse](https://vibeverse.lol) desktop app: the same site in its own window.

Get the latest from [Releases](https://github.com/Sashgnar/vibeverse-desktop/releases/latest).

**Windows:** the installer isn't code-signed yet, so Windows shows "Windows protected your PC". Choose **More info**, then **Run anyway**.

VibeVerse works fully in a browser; the app is optional.
